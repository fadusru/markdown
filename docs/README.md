# О проекте

Markdown стал стандартом документирования кода. Его синтаксис поддерживает большинство сред разработки и 
инструментов версионирования кода (GitHub, Gitea, GitLab и др.).

Данную документацию пишу в первую очередь для себя в качестве "шпаргалки".

Оставляйте свои предложения и замечания в комментариях. Они помогут сделать документацию более полной.
